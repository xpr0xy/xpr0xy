# 🂡

building local-first instruments for bass music. draw the movement, shape the sound, audition it, export the WAV.

- [pocket](https://github.com/xpr0xy/daily-2026-09-12-pocket): two-step drums and sub, WAV + MIDI.
- [throat](https://github.com/xpr0xy/daily-2026-09-10-throat): draw vocal movements over a low reese.
- [vessel](https://github.com/xpr0xy/daily-2026-09-11-vessel): design spaces, export convolution impulses.
- [backdraft](https://github.com/xpr0xy/daily-2026-09-09-backdraft): reverse chamber pickups from local audio.
- [clatter](https://github.com/xpr0xy/daily-2026-09-08-clatter): metallic percussion loops with per-hit control.
- [afterbody](https://github.com/xpr0xy/daily-2026-09-07-afterbody): draw four-band amplitude envelopes.
