# 🂡

building browser instruments for bass music: two-step drums, formant bass, and sound-shaping tools. audition locally, export WAV. no accounts, no uploads.

- [pocket](https://github.com/xpr0xy/daily-2026-09-12-pocket): two-step drums and sub; WAV + MIDI export.
- [throat](https://github.com/xpr0xy/daily-2026-09-10-throat): draw vowel movements over a low reese.
- [vessel](https://github.com/xpr0xy/daily-2026-09-11-vessel): draw decay and tone; export a stereo impulse response.
- [backdraft](https://github.com/xpr0xy/daily-2026-09-09-backdraft): shape reverse chamber swells from your own one-shots.
- [clatter](https://github.com/xpr0xy/daily-2026-09-08-clatter): metallic percussion loops with per-hit timing and dynamics.
- [afterbody](https://github.com/xpr0xy/daily-2026-09-07-afterbody): sculpt bass and drum one-shots with four-band envelopes.
