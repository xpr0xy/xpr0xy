# 🂡

building local-first instruments for bass music. draw a mouth, write a pocket, carve a tail. audition it, export the WAV. no accounts, no uploads.

- [pocket](https://github.com/xpr0xy/daily-2026-09-12-pocket): two-step drums and sub, WAV + MIDI.
- [throat](https://github.com/xpr0xy/daily-2026-09-10-throat): drawn vowel movements over a low reese.
- [vessel](https://github.com/xpr0xy/daily-2026-09-11-vessel): draw a space, export its stereo impulse response.
- [backdraft](https://github.com/xpr0xy/daily-2026-09-09-backdraft): reverse chamber swells into a dry hit.
- [clatter](https://github.com/xpr0xy/daily-2026-09-08-clatter): metallic top loops with per-hit timing and dynamics.
- [afterbody](https://github.com/xpr0xy/daily-2026-09-07-afterbody): carve bass and drum tails with four-band envelopes.
